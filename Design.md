Tu es un **Senior UI/UX Designer, Product Designer et Directeur Artistique digital** avec une forte expertise en interfaces web modernes, design systems, SaaS et produits premium.

Je veux que tu **refondes entièrement le design de ce projet**, avec une approche professionnelle de niveau production.

### Objectif

Améliorer significativement l’interface existante pour la rendre :

* plus moderne
* plus élégante
* plus cohérente
* plus premium
* plus intuitive
* plus lisible
* plus agréable à utiliser
* visuellement plus forte
* cohérente sur desktop, tablette et mobile

**Important : ne pars pas sur une nouvelle identité visuelle.**

Tu dois **conserver et respecter la charte graphique déjà présente dans le projet** : couleurs, identité visuelle, logo, typographies, éléments graphiques et personnalité de la marque.

Ton travail consiste à **faire évoluer et professionnaliser l’existant**, pas à le remplacer arbitrairement.

### 1. Commence par analyser l’existant

Avant de modifier le code, analyse attentivement :

* la structure du projet
* les pages existantes
* les composants
* la navigation
* la hiérarchie visuelle
* les couleurs déjà utilisées
* les typographies
* les espacements
* les boutons
* les cartes
* les formulaires
* les états hover/focus/active/disabled
* les icônes
* les tableaux
* les modales
* les messages d’erreur et de succès
* le responsive
* les incohérences visuelles éventuelles

Identifie également les problèmes UX/UI qui nuisent à la compréhension ou à l'expérience utilisateur.

### 2. Respect strict de la charte graphique

Ne change pas arbitrairement :

* les couleurs principales
* la palette de marque
* le logo
* les codes visuels fondamentaux
* la personnalité graphique
* les éléments qui permettent d'identifier la marque

Tu peux en revanche **optimiser leur utilisation** :

* contrastes
* proportions
* hiérarchie
* nuances secondaires
* backgrounds
* bordures
* ombres
* états interactifs
* équilibre visuel

L'objectif est que l'on reconnaisse immédiatement la même marque, mais avec une interface beaucoup plus professionnelle.

### 3. Repenser le système UI

Crée une vraie cohérence entre les composants.

Travaille notamment sur :

* grille et layout
* spacing system
* border radius
* typography scale
* tailles et variantes de boutons
* inputs
* selects
* cards
* badges
* tables
* navigation
* sidebar
* headers
* modales
* dropdowns
* tooltips
* notifications
* loaders
* empty states
* error states
* success states

Tous les composants doivent sembler appartenir au **même design system**.

### 4. Hiérarchie visuelle

Chaque page doit avoir une hiérarchie claire.

L'utilisateur doit comprendre immédiatement :

1. où il se trouve
2. quelle est l'information principale
3. quelle action est prioritaire
4. quelles informations sont secondaires
5. quelles actions sont disponibles

Évite les interfaces surchargées, les éléments visuellement concurrents et les blocs inutiles.

Utilise intelligemment :

* taille
* poids typographique
* contraste
* espace négatif
* alignement
* regroupement
* profondeur
* couleur

### 5. UX

Ne te limite pas à l'esthétique.

Améliore également :

* la navigation
* la compréhension des actions
* les parcours utilisateur
* les feedbacks
* les états des composants
* la prévention des erreurs
* la lisibilité
* la réduction de la charge cognitive

Chaque interaction importante doit avoir un feedback visuel clair.

### 6. Responsive design

Le design doit être réellement responsive.

Ne te contente pas de réduire les dimensions.

Repense si nécessaire :

* la navigation mobile
* les colonnes
* les tableaux
* les cartes
* les formulaires
* les boutons
* les espacements
* la hiérarchie des informations

Teste mentalement et techniquement les différentes tailles d'écran.

### 7. Direction artistique

Adopte une direction artistique **sobre, moderne, premium et cohérente avec l'identité existante**.

Évite les tendances UI utilisées uniquement pour faire "joli" :

* gradients excessifs
* glassmorphism gratuit
* ombres trop fortes
* animations inutiles
* effets flashy
* couleurs supplémentaires sans justification
* surutilisation des bordures
* composants trop arrondis sans raison

Chaque choix esthétique doit servir la lisibilité et l'expérience utilisateur.

### 8. Animations et micro-interactions

Ajoute uniquement des animations utiles et élégantes :

* hover
* focus
* transitions
* ouverture/fermeture
* feedback d'action
* loading
* changement d'état

Les animations doivent être rapides, fluides et discrètes.

### 9. Qualité du code

Ne détruis pas l'architecture existante inutilement.

Avant de modifier un composant, vérifie comment il est utilisé ailleurs.

Privilégie :

* composants réutilisables
* variables/design tokens
* cohérence des styles
* code maintenable
* absence de duplication
* responsive propre
* accessibilité

Évite les hacks CSS et les corrections ponctuelles qui créent de nouvelles incohérences.

### 10. Méthode de travail

Travaille dans cet ordre :

**Analyse → Architecture UI → Design system → Composants → Pages → Responsive → Micro-interactions → Vérification finale**

Ne fais pas une simple retouche cosmétique.

Je veux une **véritable refonte UI/UX**, tout en conservant l'identité visuelle existante.

### Critère final

À la fin, le projet doit donner l'impression d'avoir été conçu par une **équipe senior de Product Designers et de développeurs frontend**, avec :

* une identité cohérente
* une hiérarchie visuelle forte
* une excellente lisibilité
* des composants cohérents
* une navigation intuitive
* un responsive propre
* une finition visuelle premium

**Ne modifie pas la charte graphique pour le plaisir de changer. Améliore-la dans son utilisation et respecte l'identité existante.**

Commence par **inspecter et comprendre l'intégralité du projet**, puis applique la refonte directement dans le code.

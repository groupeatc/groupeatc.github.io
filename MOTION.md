# Motion system — Groupe ATC

Briefs de référence : `motionDesign1-ATC.md`, `motionDesign2-ATC.md`, `motionDesign3-ATC.md`.

Principe : **le site bouge comme un chantier avance — chaque geste a une raison.**
Une seule idée porte l'identité : **le trait**, la ligne de construction orange `#E45204`.

## Rythme de la page d'accueil

Ouverture « le chantier sort du plan » (**WOW**, puis loupe « Vue plan ») → À propos / carte (**WOW** : le réseau se trace) → Vidéo (**silence**) →
**WOW** : le plan devient la structure, puis tout un site en service → Engagement (**silence** : une phrase du groupe, rien ne bouge) →
Réalisations (en défilement horizontal sur mobile) + logos clients (défilement lent en boucle, pause au survol) → Engagements Qualité · Sécurité · Environnement (**confiance** : trois sceaux de certification se dessinent puis se tamponnent l'un après l'autre, reliés par le trait) → Fin : « Parlons de votre projet », avec l’heure en direct au siège de Bamako (point orange qui pulse doucement), boutons contact et téléphone.

## Règles

- N'animer que `transform`, `opacity`, `clip-path`, `stroke-dashoffset`.
- Easing unique : `--ease-out`. Pas de rebond.
- Tout le contenu est visible sans JavaScript et sous `prefers-reduced-motion` (photo affichée directement sans tracé, pas de transitions de page, pas de parallaxe).
- Parallaxe : desktop uniquement (≥ 768 px), mesurée sur le conteneur, ignorée hors écran.
- Transitions de page : amélioration progressive (View Transitions entre documents). Un seul élément nommé `project-media` par page : la carte cliquée côté départ, `.project-hero--shared` côté fiche projet. Ajouter cette classe à toute nouvelle fiche projet.
- Chiffres : comptage unique, uniquement pour des valeurs validées ; jamais de fausse donnée « en direct ».
- Avant d'ajouter une animation, vérifier si une forme du trait existante peut servir.
